# Optional Property

Get a property from an object

```sig
TypeScriptExpanded.optionalProperty()
```

## Parameters
- **object**: The object to access
- **property**: The property name to access

## Example

```blocks
let playerData = {
    name: "Player",
    health: 100
}

let health = TypeScriptExpanded.optionalProperty(playerData, "health")
```
